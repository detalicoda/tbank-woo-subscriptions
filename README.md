# T-Bank для WooCommerce Subscriptions

Плагин WordPress для приёма регулярных и разовых платежей через Т-Банк Эквайринг с сохранением карт клиентов.

## Требования (+-)
- WordPress 6.9
- PHP 8.2
- WooCommerce 10.7
- WooCommerce Subscriptions 8.5

## Установка
1. Скачайте ZIP-архив плагина.
2. Загрузите папку `tbank-woo-subscriptions` в `/wp-content/plugins/`.
3. Активируйте плагин в разделе «Плагины».
4. Перейдите в WooCommerce → Настройки → Платежи и настройте «Т-Банк (Подписки)».

## Настройка
Получите "Terminal Key" и "Secret Key" в личном кабинете Т-Банк Эквайринга.
